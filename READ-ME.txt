ROTK CPU Manager — portable version 1.4.1
Dedicated CPU assistant for the ROTK / Z1BR client.

GETTING STARTED
1. Run ROTK-CPU-Manager-EN.exe on 64-bit Windows 10 or 11.
2. The default folder is C:\Games\ROTK. Click Browse if installed elsewhere.
   The selected folder must contain H1Z1.exe and rotkc.dll (ROTK client).
3. Read the recommended profile and its explanation.
4. Click APPLY AND MONITOR. The game can be running already or started later.
   The selected profile is automatically applied to H1Z1.exe in this folder.
5. RESTORE AND STOP puts back the original settings and stops monitoring.
   Closing the application also restores a running game's original settings.

WINDOW AND SCROLLING
Minimize, maximize and close are integrated into the application's top bar.
Drag that bar to move the window; use its edges and corners to resize it.
The themed scrollbars support the wheel, dragging and keyboard navigation.
When a scrollbar is focused, use arrows, Page Up/Down, Home and End.
Main action buttons and the guide button remain visible on smaller windows.
Minimizing hides the window to the notification area and keeps monitoring active.
Double-click its icon to reopen, or use Exit and restore to fully close it.

LANGUAGES
ROTK-CPU-Manager-FR.exe starts in French; ROTK-CPU-Manager-EN.exe starts in English.
Both include FR / EN buttons to change language without stopping monitoring.
The generic ROTK-CPU-Manager.exe remembers your chosen language for the next launch.
All versions share preferences and prevent concurrent instances.

RELEVANT CPUS (EXAMPLES)
- Hybrid Intel: i5-12600K/KF, i7-12700K/KF, i9-12900K/KF;
  i5-13600K/KF, i7-13700K/KF, i9-13900K/KF; i5-14600K/KF,
  i7-14700K/KF, i9-14900K/KF; Core Ultra 200S / 200S Plus.
  P-cores recommended when Windows identifies at least four physical cores.
- Asymmetric-cache AMD X3D: Ryzen 9 7900X3D, 7950X3D, 9900X3D, 9950X3D.
  Large-cache group recommended only when detected cache sizes confirm it.
- AMD with comparable L3 groups: Ryzen 9 5900X, 5950X, 7900X, 7950X,
  9900X, 9950X, 9950X3D2 Dual Edition. Windows recommended; group trials.
- Single-group AMD X3D: 5800X3D, 7800X3D, 9800X3D, 9850X3D.
  Windows recommended; without-SMT trial, no CCD selection.
- Ryzen 5 3600 / 3600X: Windows recommended; 6-thread trial instead of 12.
  L3 groups with fewer than four physical cores are not offered.
- Intel without P/E-cores: Windows recommended; without-HT trial if there are
  at least four physical cores with multiple threads per core. No HT: Windows only.
Non-exhaustive examples, not a list of validated gains. Hardware checks were
performed on an i9-13900KF; other topologies are checked through simulation.

PROFILES
- Hybrid Intel: performance cores are recommended when at least four are detected.
- AMD with asymmetric L3 cache groups: favors the substantially larger cache group.
- AMD with equal-sized L3 groups: group profiles are trials; Windows is the default.
- Classic or insufficiently identified topology: Windows management is recommended.
- No SMT / Hyper-Threading: a trial using one logical thread per physical core.
  SMT is not disabled for other applications and no BIOS setting is changed.
- Multiple processor groups: only Windows management is offered.
The recommendation is based on topology, not a ROTK benchmark. Compare similar
scenes and focus on stutter and frame times as well as FPS. Open UNDERSTAND THE
SETTINGS for the complete guide. This application does not measure FPS.

SCOPE AND RESTORATION
Only H1Z1.exe directly inside the selected ROTK folder is targeted. LaunchPad,
BattlEye, a retail H1Z1 installation elsewhere and other applications are untouched.
No game file, system priority, driver, service, hard affinity, global Windows
setting or core parking setting is modified. The app uses Windows CPU Sets APIs.
Existing hard affinity and per-thread CPU Sets can limit a profile's effect.
Windows management clears default CPU Sets. Restore puts back the exact default
CPU Sets that were present before this tool applied its first change.
If restoration fails, closing is cancelled so it can be retried.
If the app crashes or is forcibly terminated, restart the game to reset its CPU Sets.

TROUBLESHOOTING
If access is denied and ROTK is elevated, close this tool and run it as administrator.
A protected process may still reject access; this tool does not bypass protection.
The executable is unsigned, so Windows SmartScreen may show a prompt. Verify its
source and compare the SHA-256 hash with the included checksum file.

SHARING / REQUIREMENTS
Share the FR or EN portable ZIP, or its single executable.
Requires .NET Framework 4.8, included in recent Windows 10 and Windows 11.
No SDK, NuGet packages, modern .NET runtime download or installation is needed.
On an older Windows 10 without Framework 4.8, update Windows or install that runtime.
Preferences: %LOCALAPPDATA%\ROTK CPU\settings.xml.
Monitoring must be enabled and this app must be open to detect game launches.
It does not start with Windows, launch the game or use the network. No telemetry.
To uninstall, close it, delete the executable and optionally its preferences folder.
